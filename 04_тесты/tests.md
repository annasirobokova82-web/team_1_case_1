**Вход:**
Создание платежа по данным из `payments.csv`: `order\\\_id = ord\\\_1001`, `amount = 2500.00`, `currency = RUB`, `recipient = clinic\\\_medservice`.

## T1-5. Таймаут эмулятора

**Вход:**
Платёж с `order\\\_id`, для которого эмулятор шлюза (по хэшу) возвращает `TIMEOUT`: `order_id: "ord_1009"`, `amount: 900`, `currency: "RUB"`

**Ожидание:**

* Клиенту возвращается статус `TIMEOUT` (платеж в обработке).

* Повторный запрос с тем же `Idempotency-Key` безопасен.

**Факт:** В интерфейсе появилось окно "Таймаут: Банк не отвечает. Попробуйте позже".

## T1-6. Повтор запроса (Идемпотентность)

**Вход:**
Два запроса на создание/подтверждение платежа с одинаковым `Idempotency-Key` (`idem_test_123`) и одинаковым `order_id: "ord_1001"`.

**Ожидание:**

* Второй запрос не создает дубликат.
* Возвращается ошибка `DUPLICATE_ORDER` (повторное списание запрещено).
* В `payments_out.csv` не добавляется новая запись.

**Факт:**  При повторном нажатии в интерфейсе появилось окно "Дубликат заказа: Этот заказ уже был оплачен ранее. Повторное списание запрещено".
**Пройден:** \[x] да \[ ] нет
