# Платёжный сервис для клиники «Мед-Сервис»

##  Описание кейса
В рамках кейса «Платёжный сервис: безопасный платёж за услугу» командой **API-молодцы** был разработан сервис для интеграции в мобильное приложение клиники. Сервис позволяет пациентам оплачивать медицинские услуги онлайн, а также поддерживает возврат средств и отправку уведомлений.

##  Основные возможности
*   **Создание платежа:** Валидация входных данных (сумма, валюта, получатель).
*   **Безопасность:** Защита от двойного списания (Идемпотентность), проверка форматов данных, защита от Replay-атак (Timestamp/Nonce).
*   **Эмулятор шлюза:** Детерминированная имитация ответов банка (Успех, Отказ, Таймаут).
*   **Возврат средств:** Метод `POST /refund` для отмены записи и возврата денег.
*   **Уведомления:** Метод `POST /notifications` для отправки SMS пациенту и оповещения клиники.

##  Структура проекта
*   `01_данные/` — Исходные данные (`payments.csv`, `recipients.csv`) и результаты тестов (`payments_out.csv`).
*   `02_документация/` — Требования (`04_requirements.md`), правила валидации (`02_правила.md`), словарь данных (`03_data_dictionary.md`) и описание эмулятора(`07_confirmation.md`).
*   `03_код/` — Исходный код:
    *   `05_app.py` — Бэкенд (CLI-прототип).
    *   `interface_demo.py` — Визуальный интерфейс на Tkinter.
    *   `test_payment.json` — Пример JSON-запроса для тестирования.
*   `04_тесты/` — Тест-сценарии (`tests.md`).
*   `05_api/` — Спецификация API в формате OpenAPI 3.0 (`06_openapi.yaml`).
*   `06_презентация_и_приложение/` — Итоговое приложение (`06_приложение.md`) и презентация (`Презентация.pptx`).
